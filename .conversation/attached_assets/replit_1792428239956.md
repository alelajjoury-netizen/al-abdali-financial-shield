# درع الأمان المالي

## Problem
[الشباب والموظفون الجدد] يعانون من [النزيف المالي والندم المتكرر بسبب الشراء العاطفي والقهري] لأن [مناعتهم المالية تكون ضعيفة في أوقات التوتر أو السهر المتأخر، مما يدفعهم للشراء اللحظي دون تفكير ولا توجد فرامل سلوكية تمنعهم قبل إتمام عملية الشراء].

## User
الشباب والموظفون الجدد (21 - 29 سنة) الذين يستلمون رواتبهم ويعتمدون كلياً على التسوق الإلكتروني وتطبيقات التوصيل ويسهرون لأوقات متأخرة.

## Solution
نساعد [الشباب والموظفين] على حل [مشكلة الشراء العاطفي والنزيف المالي] عن طريق [منصة بنك وافتراضي تزودهم ببطاقة ذكية تفرض مهلة تهدئة إجبارية وقواعد فرامل سلوكية قبل إتمام أي عملية شراء مشبوهة].

## Differentiator
منصة بنك وهمي تقدم بطاقة افتراضية ذكية ترتبط بـ "درع الأمان المالي" يربط أمان الحساب البنكي والبطاقات بـ "الحالة النفسية والزمنية" للمستخدم وليس فقط برقم OTP تقليدي، مع وجود زر التبريد المالي وتنبيهات ذكية بلغة صديقة.

## MVP features (build only these)
- حساب وبطاقة افتراضية (Virtual Card) مع لوحة تحكم لتفعيل وضع الحماية العاطفية.
- محاكاة عملية الشراء مع تفعيل مهلة التهدئة الإجبارية (Cool-down Timer) عند الشراء في أوقات الحظر.
- أسئلة التوعية الذكية وزر تأجيل الشراء لتفعيل التفكير العقلاني قبل الخصم.

## Vision (do not build yet)
التوسع لربط المنصة بحسابات البنوك الحقيقية عبر خدمات المصرفية المفتوحة (Open Banking)، واستخدام الذكاء الاصطناعي السلوكي لتحليل أنماط الإنفاق والمؤشرات الحيوية عبر الساعات الذكية لمنع القرارات المالية الخاطئة تلقائياً.

## Stack
- Frontend: React with Vite
- Backend: Node.js and Express
- Database: MongoDB Atlas with Mongoose
- Payments: Stripe test mode only, if needed

## Rules
- Build one feature fully, then the next.
- Small steps. Explain each change.
- Never put secrets in code. Use Replit Secrets or .env.
- Do not add features that are not in the MVP list.
